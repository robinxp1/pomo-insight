# 番茄洞察 · 工作节奏追踪器

[![License: MIT](https://img.shields.io/badge/License-MIT-63E6BE.svg)](LICENSE)

> pomo-insight —— 一个安静待在屏幕边缘的番茄工作法 / 工作节奏记录器。

一个可吸附在屏幕边缘、贴边自动隐藏的极简开发工时记录器。原生 Windows PowerShell + WPF 实现，**不打包 exe、不联网、不写入 Excel**，数据只保存在本机。

适合记录“今天在电脑前真正推进了哪些开发工作”，并把记录导出成 JSON / CSV，交给 AI 分析工作节奏和习惯。

## 快速开始

1. 双击 `启动番茄洞察.cmd`。
2. 首屏只有一个输入框、播放键和右侧箭头。输入工作内容后点播放键或按 Enter 开始。
3. 点击输入框会展开近期工作建议；继续输入会自动过滤，点击条目即可填入。重复点击输入框不会让下拉反复开关。
4. 工作时点“结束并保存”完成记录；需要休息时点“现在休息”。
5. 点右侧小箭头展开，可查看今天统计、今日工作段（支持“更改”和“补录”）、导出和设置。
6. 首次使用建议进设置打开“开机自动启动”。
7. 运行后托盘会出现番茄洞察图标：左键唤出浮窗，右键只有“设置”和“关闭程序”。

首次启动时 Windows 可能短暂闪一下命令行窗口，之后通过开机自启运行不会出现。

## 它记录什么

每段记录包含：

- 工作内容、开始/结束时间、日期、星期、起始小时。
- 今日工作段支持更改开始/结束时间或补录遗漏的工作时间；保存后会重新计算该段的实际工作时长。
- 统计卡里的“非工作”包含段内休息、段间空档和计时空洞，用来还原一天在电脑前的工作时间分布。
- 墙钟时长、休息时长、实际工作时长。
- 休眠/待机造成的计时空洞会单独标记，并从实际工作时长、最长连续专注中扣除，下一次提醒也会顺延。
- 最长连续专注时长、休息次数、提醒次数、延后次数。
- 每次休息的开始/结束/实际时长/计划时长。
- 行为事件流：开始、休息提醒、延后、休息开始、休息结束、结束、更改、异常恢复等。
- 结束原因：手动结束、退出程序、系统关闭、异常恢复、事后更改、补录。

这些字段足以让 AI 分析：

- 你一天中效率最高的时段。
- 什么任务最容易进入长专注。
- 50 分钟提醒是否经常被延后。
- 哪些日子更容易少休息、超长工作或频繁中断。
- 适合你的下一次节奏调整。

## 提醒模型

默认是 **50 分钟软提醒 + 10 分钟休息 + 90 分钟健康护栏**。设置页还提供三个一键预设：**番茄 25/5**、**平衡 50/10**、**52/17 观察**；选择后会显示对应模式的介绍和适用场景，也可以保留预设后继续手动微调。预设只是起点，不是普适医学结论。

默认模型的行为：

- 到 50 分钟时右下角出现提醒，但不会强制中断。
- 可以“再工作 10 分钟”，最多延续到 90 分钟。
- 到 90 分钟后提醒变强，延后时间缩短为 5 分钟。
- 休息时间单独计时，并从实际工作时长中扣除。
- 休息采用正向计时：显示已经休息多久，而不是倒计时；休息超时也会被准确记录。
- 休息 30 秒后，右下角提醒和主浮窗会一起隐藏；检测到鼠标活动时再恢复，避免同事或领导看到休息界面。
- 可选 20-20-20 护眼轻提醒，默认关闭，避免每 20 分钟打断心流。

这不是“唯一科学正确”的番茄钟替代方案。现有研究并不支持一个普适的最佳比例，因此所有数值都可以在设置里调整。详细依据见 `docs/reminder-model.md`。

## 导出给 AI

展开浮窗后：

- **导出JSON**：完整结构化数据，包含汇总、设置、提醒模型和逐段记录，推荐给 AI。
- **导出CSV**：一行一段记录，适合表格/脚本处理。
- **导出AI解读提示词**：生成字段说明和建议分析问题，可直接交给 AI。

三个按钮等宽并靠右排列。每次导出都会先弹出标准 Windows 保存位置窗口，由你选择文件名和目录；不会强制写入某个固定目录。导出后会打开资源管理器并选中文件。没有任何 Excel 文件。

可以直接对 AI 说：

> 这是我用番茄洞察记录的开发工时 JSON。请分析我的高效时段、任务时长分布、休息依从性和专注节奏，并给出下周可执行的调整建议。不要只看总时长，也关注最长连续专注、延后提醒次数和休息结构。

## 浮窗行为

- 未开始工作时，浮窗强制置顶并保持前台，不能贴边隐藏，提醒你先记录再工作。
- 开始工作后，可按住浮窗空白处拖动到任意显示器；靠近当前显示器的左/右/上/下边缘 42px 都会吸附。
- 左/右/上边缘会继续自动隐藏；底部只停靠，不会隐藏。
- 多显示器之间的中缝不会被当作可隐藏边缘，避免在中缝处反复展开/收起。
- 工作时贴边收起后，当前显示器顶部中央会显示一个鼠标穿透的极小时长条，仅显示本轮持续时间；鼠标移到上面时会自动变半透明，减少对下方内容的遮挡。
- 鼠标移到贴边位置即可恢复主浮窗；收起/展开带有短暂冷却，鼠标停在贴边处不会反复抽动。
- 休息时允许贴边；休息 30 秒后所有浮窗都会隐藏，鼠标移动后恢复。
- 浮窗不进入任务栏，不需要管理员权限。

## 数据与隐私

- 默认数据目录：`%LOCALAPPDATA%\PomoInsight`
- 可在设置页“数据存储位置”更改数据目录；更改时会复制现有记录，之后的新记录写入新目录。
- 数据目录指针：`%LOCALAPPDATA%\PomoInsight\data-location.json`（选择自定义目录后用于下次启动定位）
- 主数据：`sessions.json`
- 当前会话恢复快照：`active-session.json`
- 设置：`settings.json`
- 日志：`pomoinsight.log`
- 代码中没有任何网络请求、遥测、账号体系或云同步。
- 程序不使用管理员权限。
- 如果进程异常退出，下次启动会用 30 秒心跳快照自动补存上一次记录。

## 开机自启与退出

- 设置里勾选“开机自动启动”会在当前用户的启动目录创建快捷方式：
  `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\PomoInsight.lnk`
- 启动项图标取自 `assets\pomo-insight.ico`（绿色播放键），不再是 PowerShell 默认图标。
- 不需要管理员权限，不写 HKLM 注册表。
- 退出：展开 → 设置 → 退出番茄洞察，或右键托盘图标选择“关闭程序”。正在计时时退出会提示并保存当前记录。
- 托盘图标：左键唤出番茄洞察；右键菜单只有“设置”和“关闭程序”两项。
- 如果移动了程序文件夹，请重新进设置保存一次，自启路径会更新。

## 资源占用

- 使用 Windows 自带的 PowerShell 5.1 / WPF，不安装 Electron、Node、Python 或浏览器内核。
- 计时中每秒刷新一次；空闲时降到每 30 秒一次。
- 空闲且无计时会话时，会主动回收工作集，降低物理内存占用。
- 无后台网络、无自动更新、无常驻服务。

## 兼容性

- Windows 10 / 11，Windows PowerShell 5.1。
- 不需要安装 .NET 运行时（系统自带）。
- 如果公司电脑通过 AppLocker / 组策略禁止运行 PowerShell 脚本，本工具无法绕过该限制；那属于系统策略，不是换成 exe 就能解决。
- 浮窗不进入任务栏，默认置顶，可关闭置顶。

## 绿色免安装包

`dist\pomo-insight-1.2.0-portable.zip` 是可直接分发的绿色版：

- 解压后双击「启动番茄洞察.cmd」即可运行，不安装、不写注册表、不需要管理员权限。
- 包内带 `portable.dat` 标记，程序会把记录和设置写在同目录的 `data\` 下，整个文件夹可以直接拷到 U 盘或另一台电脑继续用。
- 卸载就是关掉程序后删掉文件夹，不残留数据。
- 需要重新打包（版本号取自 `lib\PomoInsight.Core.ps1`，会自动命名）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\Build-Portable.ps1
```

图标资源由 `tools\New-AppIcon.ps1` 生成，输出 `assets\pomo-insight.ico`（16/24/32/48/64/128/256 多尺寸）。

## 文件结构

```
PomoInsight.ps1             主程序：窗口、计时状态机、提醒
lib\PomoInsight.Core.ps1    本地存储、统计、导出、自启
ui\MainWindow.xaml        主浮窗界面
ui\ReminderWindow.xaml    右下角提醒界面
ui\MiniTimerWindow.xaml   贴边隐藏时的顶部迷你计时条
assets\pomo-insight.ico      应用图标（启动项、窗口）
启动番茄洞察.cmd         便携启动器
tools\Build-Portable.ps1  打绿色免安装包
tools\New-AppIcon.ps1     重新生成应用图标
dist\                     打包输出目录
tests\                    语法、核心数据和运行时冒烟测试
docs\reminder-model.md    提醒模型与研究依据
```

## 测试

在 PowerShell 中运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\SmokeAll.ps1
```

也可以逐个运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\ParseScripts.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\CoreSmoke.ps1
powershell -NoProfile -STA -ExecutionPolicy Bypass -File .\tests\ParseUi.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\UiSmoke.ps1
```

`UiSmoke.ps1` 会实际启动界面，跑一遍“开始 → 定时提醒 → 延后 → 休息 → 继续 → 结束 → 导出”，并检查托盘、顶部不隐藏、节律预设和多显示器吸附，然后自动退出。
